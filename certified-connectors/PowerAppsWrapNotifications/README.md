## Power Apps Wrap Notifications
Wrap Notifications allows you to send Push Notifications to your Wrapped Power Apps Mobile Apps.

## Prerequisites
You will need the following to proceed:
* A Google Firebase cloud project
* Previously configured your Wrapped app Push Notifications following existing documentation.

## Supported Operations
The connector supports the following operations:
* `sendNotification` sends a notification to 1, many or all users of your custom wrapped app.
